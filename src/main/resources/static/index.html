How LendLoop Works

Start sharing resources in four simple steps.

1

Register

Create your student account and join the LendLoop campus community.

2

Find Items

Browse available resources listed by other students.

3

Send Request

Select an item and send a borrowing request to its owner.

4

Borrow & Return

Collect the approved item and return it within the agreed duration.
